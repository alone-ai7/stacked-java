# 📚 Project Name Here

> **`System.out.println("Too many Java books in the library");`**

Welcome to the repository! This project exists because if you walk into our school library and accidentally trip, you will land on three copies of *Introduction to Java Programming*, a dusty manual on Java 5. 

Since our school's physical infrastructure is 90% Java literature, I figured it was only fair to contribute to the digital pollution.

---

## 🏛️ The Library Backstory
* **Total books in the school library:** 10,000
* **Total Java books:** 9,999
* **Books about any other language:** 1 (It's a textbook on COBOL from 1984)

This code was compiled using the absolute weight of endless stacks of Java documentation sitting on our library shelves. 

## 🚀 Features
* **100% Caffeinated:** Powered by the sheer energy of the coffee emoji ☕.
* **School Library Approved:** Built out of spite and the lack of variety in our curriculum resources.
* **Memory Efficient:** Unlike the physical library shelves, this won't collapse under the weight of `PublicStaticVoidMustDie`.

## 🛠️ Requirements
* A computer (obviously).
* Java Development Kit (JDK) installed.
* A library card (strictly to look at more Java books if this code doesn't work).

## 🏃‍♂️ How to Run
1. Go to the school library.
2. Find the 4th row of Java books.
3. Whisper `public static void main` to the librarian.
4. Or, just clone this repo and run:
   ```bash
   javac Main.java
   java Main
   ```
